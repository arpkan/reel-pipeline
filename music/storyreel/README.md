# StoryReel music library

The background tracks are **not committed** to keep the repo small. `index.json` lists each
track's genre, energy, tempo, attribution and source page.

To use StoryReel locally, download each track from its source page and save it at the path
shown below (relative to this folder).

All tracks are licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Credit the
artist when publishing videos that use them.
